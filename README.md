# Treehouse Therapy Center - Premium WordPress Theme

A premium, conversion-focused WordPress theme for Treehouse Therapy Center, featuring modern design patterns inspired by top ABA therapy websites.

## 🌳 About

Treehouse Therapy Center provides evidence-based ABA therapy helping Minnesota families reach their full potential. This custom WordPress theme delivers a warm, trustworthy, and professional web presence optimized for parent engagement and conversions.

## ✨ Features

- **Premium Design**: Matching quality of leading ABA therapy websites (Webisserie standards)
- **Brand Colors**: Complete implementation of Treehouse brand palette
- **Tailwind CSS**: Modern utility-first styling
- **Scroll Animations**: Smooth, engaging user experience
- **Mobile-First**: Fully responsive across all devices
- **Performance Optimized**: Fast loading, SEO-ready
- **Accessibility**: WCAG 2.1 AA compliant
- **Contact Forms**: Ready for Contact Form 7 integration

## 🎨 Design Elements

- Wave dividers between sections
- Floating animated elements
- Custom treehouse icon/logo
- Premium card designs with hover effects
- Gradient text effects
- Professional photography integration
- Smooth page transitions

## 📋 Pages Included

- **Homepage**: 11 premium sections (hero, services, testimonials, etc.)
- **About Us**: Mission, values, team
- **Services**: Detailed service pages
- **Contact**: Full contact form and info
- **Careers**: Job listings

## 🛠️ Installation

1. Download or clone this repository
2. Upload to `/wp-content/themes/treehouse-therapy-2024/`
3. Install dependencies: `npm install`
4. Build CSS: `npm run build`
5. Activate theme in WordPress admin
6. Customize via WordPress Customizer

## 📦 Build Commands

```bash
# Development (watch mode)
npm run dev

# Production build
npm run build

# Build JavaScript
npm run build:js
```
